# Third-party materials and license boundaries

## Original project code

The study authors license their original code under MIT (`code/LICENSE`). The
scope is code, not a blanket relicensing of every file in the repository.
Historical third-party notices take precedence for externally sourced content.

## Morimoto source repository

Source: <https://github.com/takuma929/gloss_tinynetworks>.
The locally supplied repository carries an MIT license, Copyright 2025
Takuma Morimoto. The original notice is retained as
`code/third_party/Morimoto/LICENSE`. Selected unmodified `.m` files and their
SHA-256 hashes are included there for methodological provenance. The complete
third-party repository, trained networks, participant CSVs and source-paper PDFs
are not redistributed in this lightweight release.

Selected stimulus thumbnails and associated published labels used in the
figures originate from that author-provided source. Retain the source attribution
and original license. Any third-party components within the original scenes
remain subject to their own rights; the present authors do not claim additional
ownership of them. The independently implemented tiny-network control in this
study is identified separately from the author's original code and weights.

## Reconstructed reference images and HDR illumination

The reference sequence was generated by the archived project renderer using the
external `doge2.hdr` environment. Its recorded source is the KhronosGroup
glTF-Sample-Environments collection, with original environment-probe provenance
to USC ICT. The HDR file itself is omitted because its independent redistribution
terms were not established in the local provenance audit. Its download source
and SHA-256 are retained in `docs/data_external_sources.json`.
Generated reference PNGs and thumbnails are provided as experimental inputs,
with that external provenance, not under a newly asserted MIT image license.

## Models, dependencies and human data

Model weights are not distributed. InternVL and Qwen sources retain their own
model licenses and conditions at the revision-pinned upstream repositories.
The original human data retain their source attribution and license; a full
data archive is separate from this lightweight code repository. Model outputs
and analysis tables are research records, not third-party software relicensed
by `code/LICENSE`.

Python/MATLAB libraries, fonts, GPU drivers and application runtimes are not
vendored. In particular, Arial is not distributed; install it only under a valid
license, or use the plotting library's available font fallback. Downloaded
dependencies retain their own licenses.

The Serrano data extension and external HDR panorama are not included as raw
datasets in this repository. Public release of any additional third-party asset
requires its original redistribution terms to be satisfied.
